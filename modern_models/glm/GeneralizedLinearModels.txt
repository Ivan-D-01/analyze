Обобщённые линейные модели
Задания
Кроме вашего варианта набора данных, необходимо использовать набор данных flare.
1. Разделите выборку на обучающую и тестовую части.
2. Оцените параметры биномиальной логистической регрессии для каждого уровня
категориальной переменной в вашем наборе данных.
3. Оцените параметры биномиальной пробит-регрессии для каждого уровня категориальной переменной в вашем наборе данных.
4. На тестовой выборке сравните ошибки точности двух моделей выше. Сравните также
значения правдоподобия обеих моделей на обучающей и тестовой выборках.
5. Оцените параметры мультиномиальной логистической регрессии для категориальной переменной в вашем наборе данных. Оцените точность и правдоподобие этой
модели на обучающей и тестовой выборке.
6. Оцените параметры пуассоновской регрессии для количества трех типов вспышек в
нобре данных flare (т.е. три регрессии). Оцените ошибку и сравните с Гауссовской
регрессией.
Рекомендации
Функция glm из пакета stats предоставляет набор регрессионных моделей. Синтаксис этой функции аналогичен lm, однако необходимо указать семейство распределений
зависимой переменной в аргументе family. Гауссовская регрессия (аналогичная lm) указывается с помощью family = gaussian. Логистическая регрессия указывается с помощью аргумента family = binomial("logit"), а пробит-регрессия — с помощью family =
binomial("probit"). Пуассоновская регрессия доступна через family = poisson. Набор
доступных функций связи можно просмотреть, вызвав справку для family. Мультиномиальная регрессия может быть реализована с помощью функции multinom пакета multinom,
функции mlogit пакета mlogit, или функции gam пакета mgcv.
