    return (x1**2 + x2 - 5)**2 + (x1 + x2**2 - 5)**2

Ставится задача минимизировать функцию f (X). Самостоятельно реализуйте следу-
ющие методы для решения этой задачи:
• Adam (градиентный спуск)
• Метод Нельдер-Мида
• Алгоритм стаи частиц
Примените эти методы с критериями остановки по невязке целевой функции и по
погрешности приближений на произвольном уровне. Запустите алгоритмы несколько раз
с разными начальными приближениями.
